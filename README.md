# RS Software — Website Preview

This repository holds a **preview of a proposed new website for RS Software**, published on **GitHub Pages** so people can open it in a browser and review it.

> **Note:** This is a concept for review only. It is **not** the official RS Software website, and nothing here is live on the company's own web address.

**👉 View the preview:** `[https://arkaguptar778.github.io/RS-Website-Preview/]`

---

## About RS Software

RS Software helps banks, payment networks, fintechs and payment ecosystem players move billions of transactions securely, reliably and efficiently. The preview shows how the company, its payment products, its leadership team and its thinking on real-time payments could be presented.

## What's in the preview

| Section | What it covers |
|---|---|
| Home | Company overview, products, clients and partners |
| About | Company story, philosophy and patents |
| Products | **BillEdge**, **DigitalEdge**, **IntelliEdge** and **Payabbhi** |
| People | Leadership team profiles |
| Insights | Articles on ISO 20022, FedNow, request-to-pay, fraud, open banking and more |
| News | Company announcements and press coverage |
| Careers | Open roles and an application form |
| Our Culture | Life and values at RS Software |
| Investor | Investor information |
| Contact / Request a Demo | Ways to get in touch |
| Legal & Sitemap | Policies and a full page list |

## What's in this repository

```
├── index.html             Home page
├── <page>/index.html      Each page of the preview, in its own folder
├── assets/                Images, logos, team photos and videos
└── other files            Code and styling that make the pages work
```

## How to review

1. Open the preview link above.
2. Check it on **both a desktop and a phone**.
3. Share feedback with the website team.
